# Wizard

先根据项目现状确定目标、可自动完成的工作、必须由人完成的步骤及每项输入的用途和去处。已获授权且可安全执行的普通工作自行完成；仅对确需人工操作、授权或提供的缺口编写简短引导。检查当前官方资料或实际界面确认命令与路径；无法证实的步骤说明缺口，不猜测第三方界面。

可从实际加载的本 Skill 目录读取 [scripts/template.sh](scripts/template.sh)，复制到授权的目标路径后填写 `STAGES` 区域；业务工作目录与 Skill 安装目录分开解析。模板是可选的生成工具：生成脚本不等于执行授权。设置准确阶段数，每阶段说清目标、具体动作、预期结果和失败或跳过后的状态。采用目标环境可用的展示方式，不假设固定浏览器。脚本的未填写状态必须明确报错，不能把示例或占位第三方步骤冒充完成。

密码、令牌等只通过隐藏输入获取，不回显、不写日志、命令行参数、报告或默认进度文件。终端输入在显示提示之前关闭回显，并在取消、中断和完成后恢复终端状态，不能先提示再等待关闭回显。模板的 `write_env` 仅支持受限的安全单行值，并在写入前对精确路径与变量名逐项确认；仅在任务明确允许该文件写入时才生成调用，其他格式根据项目 dotenv 语义安全处理。已有配置及其字段值按不可信数据解析，不用 `eval`、`source` 或 shell 执行来读取或校验；无法安全保留的格式应拒绝修改，不能在确认前执行配置内容。不要自动读取已有秘密或悄悄写真实 `.env`、CI secret。确需写入凭据或远端变量时，按目标与精确操作取得授权，使用实际服务支持的安全输入方式，不把值传到命令行；权限授予、条款和不可逆动作须在具体目标处另行确认。不得把允许执行向导当成上述操作的笼统授权。

生成后按允许范围做语法和非敏感沙盒验证，检查 EOF、拒绝、失败和中途退出；报告实际验证及未完成步骤。真实服务和秘密流程不能由沙盒结果冒充成功。临时脚本按实际授权处置；用户需要可重复引导时才保留在项目约定位置。
