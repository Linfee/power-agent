# 分诊与调度角色 seed

按实际项目选用并填写现有 tracker 中对应的表示，不是必须创建的标签列表。可选角色包括：待分诊、待补信息、可由 Agent 实现、需人工处理、不采纳；按项目需要另映射 ready、map、research、prototype、讨论或 task 等调度/对象角色。相同概念可复用项目已有状态、字段或标签，不存在的非必要标签使用项目约定的无标签表示。仅外来请求需要分诊时记录其 Triage，不能混同实现状态。

把真实角色、字符串或字段值、何时使用和读取方式写进项目约定位置；不存在对应角色就明确写无标签处理方式。需要创建或更改远端标签时先核对对目标及写操作的授权，setup 本身不隐含此授权。
