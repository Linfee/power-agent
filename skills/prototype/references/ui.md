# 界面原型

适用于布局、信息层级或交互方案的视觉比较。围绕一个具体问题制作能体现真实差异的方案；差异应针对布局、层级或主要操作，而非仅换颜色。方案数量由决策需要决定。

有合适宿主页面时，在不破坏原行为与授权边界的前提下展示接近真实的导航、内容密度和屏幕尺寸；否则用清楚标记的独立原型。使用项目已有工具或宿主支持的展示方式。需要切换时让选项易识别、可复现，并避免干扰页面交互；不绑定框架、固定路由或浏览器。

交互默认使用隔离数据，不触发真实写入。实际打开并观察画面和关键交互，记录展示环境、选择和原因；向用户提供可用入口或准确画面。需要保留决定依据时先捕获实际版本再清理，演示结果不等于生产质量。
