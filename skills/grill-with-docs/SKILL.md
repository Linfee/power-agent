# 讨论并沉淀领域知识

结合 [grilling](../grilling/SKILL.md) 处理必要选择，以及 [domain-modeling](../domain-modeling/SKILL.md) 澄清术语、上下文和值得保留的决定。先读取既有相关知识；讨论中确认的领域概念与耐久理由有未来消费者且写入获授权时，及时更新现有权威位置，不预建文档树。需要写入时遵循 [dev-docs](../dev-docs/SKILL.md) 的项目文档协议；已有规则足以执行时不必重新委派或机械逐站调用。

普通偏好不必写成 ADR；不重复维护 CONTEXT 和 glossary。确认必要取舍后，继续用户已授权的原目标；用户只要讨论或禁止修改时，给出结论和拟议知识而不写文件或实施。不得仅因本入口涉及文档而修改未授权的实现或外部 tracker。
