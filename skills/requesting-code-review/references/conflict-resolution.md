# 双审冲突归并规则

用于 `重要性等级=高`，或常规审查发现 `实现风险=高` 后升级为 `审查强度=增强` 时，合并两个独立审查结果。

## 归并步骤

1. 先按 `file + line + category` 对问题去重。
2. 同一问题取更高 `severity`。
3. 汇总所有阻塞问题后生成统一 `### 阻塞问题`。
4. 归并 `实现风险`：双方都有证据评级时取较高等级；仅一方为 `未评估` 时采用另一方有证据的评级；双方均为 `未评估` 时保留 `未评估`。
5. 根据下述判据确定统一 `状态` 与 `下一步`。

## 判据

- 任一审查出现 `严重` 阻塞：
  - `状态=阻塞`
  - `下一步=启动修复子代理`

- 无 `严重`，但任一审查出现 `重要` 阻塞：
  - `状态=阻塞`
  - `下一步=启动修复子代理`

- 双方均无阻塞，且至少一方存在 advisory：
  - `状态=通过_含建议`
  - `下一步=继续流程`

- 双方均无阻塞且无 advisory：
  - `状态=通过`
  - `下一步=继续流程`

- 双方结论证据不足或需求口径冲突：
  - `状态=需澄清`
  - `下一步=重新审查`

## 轮次控制

- 每次修复后必须重新双审，不复用旧结论。
- 连续修复-复审 3 轮后仍为 `阻塞`：
  - `状态=阻塞`
  - `下一步=升级处理`
