# Handoff

把接手者无法从现有权威材料直接获得、却需要继续工作的上下文带过去。按用户指定的下一步和接收环境选择交付形式与位置；需要文件而用户未指定位置时，放到操作系统临时目录（`$TMPDIR`，否则 `/tmp`；Windows 使用 `%TEMP%`），并告知路径。确保接收者能访问交接和所指材料；临时位置不是长期状态库。

交接应让新上下文知道：目标和范围；已确认的关键决定及理由；当前产物及其位置；授权覆盖什么、不覆盖什么；未决问题、阻塞与下一可执行动作。仅携带实际相关的事实，区分已确认决定、假设与未验证结论。记录适用的验证证据及其来源，不把摘要当成原始证据或把未核实的工作标为完成。需要理解完整讨论或决定理由时，指向可访问的原始材料。

计划、spec、issue、diff 等已有内容用准确路径或链接引用，不重复复制。执行状态以项目现用 tracker 为准：给出指针，并提醒接手者读取最新状态和工作区后再行动；交接是某一时点的快照，不是第二进度本，也不能用旧摘要覆盖更新后的状态。若没有 tracker，指向可核实的现有事实来源，不为交接新建一套。

明确发布、远程写入、权限、破坏性操作等哪些已获授权、哪些未获授权；不能从继续工作推导额外授权。排除密钥、密码和不必要的敏感个人信息；只传接手任务所需的信息。
