# Skill 调用与发现

编写 Skill 时，检查目标宿主如何发现入口、解析 frontmatter、调用 Skill 和读取随包资源；不要仅凭某个字段推断所有宿主行为。常见入口包含 `name` 和描述适用场景的 `description`；名称、目录和实际调用指针应符合目标仓库与宿主约定。

描述是常驻的发现指针：用区分性的用户场景说明何时适用，删除身份介绍和重复触发词。新增入口意味着额外发现成本；只有独立用户目标或确有独立发现需求时才拆分。必要知识可以作为按需 reference，明确何时读取及相对路径；多处共享的工程判断指向权威来源，不复制整份规则。

Power-Agent 默认整包分发，入口均允许模型调用，并可按实际需要具名使用包内其他 Skill；不保证单个目录单独安装完整，也不因此引入强制调用链或 router。模型可调用、用户可显式调用和允许产生副作用是不同问题：调用本身不授予发布、删除或访问敏感数据等权限。

其他项目若有不同策略，以其实际宿主与授权为准。部分宿主使用 `disable-model-invocation: true`，Codex 可能使用 `agents/openai.yaml` 的 `policy.allow_implicit_invocation: false`；开关是否影响发现或上下文取决于宿主，不能凭配置推断实际行为。名称、描述或调用方式改变时，同步项目索引与直接消费者，并在目标宿主分别验证自然发现、显式调用和依赖读取。
