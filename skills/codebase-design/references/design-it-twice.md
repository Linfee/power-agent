# Design It Twice

这是高影响接口的受控比较工具，不是默认设计步骤。

## 何时使用

仅在以下任一条件成立时使用：

- 用户明确要求比较不同模块或接口方案；
- 已批准的计划确认接口将被多个稳定消费者使用，且改变成本高。

## 方法

1. 固定消费者、必须保持的领域术语、兼容性约束与可观察验收；不要让候选方案重新定义需求。
2. 形成三个真正不同的模块 / 接口方案。并行能力可用时，最多派三个独立设计者；否则顺序提出三个方案。不要只交换命名或文件位置。
3. 比较每个方案的接口负担、隐藏复杂度、删除测试、locality、seam 数量与迁移成本。
4. 选择调用方总复杂度最低、边界证据最强的方案；把理由交给计划的 Key Decisions。

## 完成判据

三个方案在接口形状或边界放置上有实质差异，且选择理由能回到消费者和可观察约束。若三个方案没有真实差异，停止比较并回到单一模块深化判断。
