# Skill 与 Harness 设计指南

以 Matt 的轻量能力组织为主干，保留能改变行动、判断、授权或验收的 Power 知识。当前决定见 [ADR-0014](adr/0014-current-baseline.md)；历史融合设计已从仓库移除，需要追溯来源时检索 Git 历史，不作为当前规范。

## 先找行为缺口

新增文字前，说明没有它时模型会在哪类任务做错什么。默认行为的无效复述、固定步数和无消费者模板可以删除，但不能仅以“模型应该懂”推断原版方法、理由或示例无用。能解释如何操作、识别坏选择、处理边界或证明结果的内容应保留，不能压成一句原则。

Skill 要具体到排除坏选择，也要保留不同的正确路径。硬边界与偏好分开：机器协议、安全和授权可以精确，工具、批量、候选、子代理与输出样式随任务选择。主文、references 和示例必须使用同一判断，不在示例里重新加入正文已删的强制流程。

## 以 Matt 原版为内容底稿

迁入或重新对照 Matt Skill 时，以固定来源 `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d` 的方法与 references 为底稿，按已确认的融合差异局部修改；不要先写摘要，再把未覆盖的方法当作默认能力。并非所有 Skill 都来自 Matt；其他来源按实际出处和许可处理。以原版的信息量和方法粒度为参照，不设相同行数或字数配额，也不为了接近较短原版而删掉有用的 Power 判断。

对照每项源方法、解释、反例、示例和模板，指出它留在主文、完整移入 reference，还是因当前目标明确冲突而替换。reference 必须能回答“怎样做”，并由主文说明何时读取；不能把多步骤实操改成“可观察、可复现”等标签就算迁入。

轻量化减少的是重复加载、无用机制、人工接力和状态副本，不是知识的完整度。没有实际对照证据，不把篇幅减少当作质量提升，也不声称内容恢复已经证明模型表现提升。

## 整包组合与渐进披露

24 个 Skill 整包分发，但安装不等于默认模型可见：14 个允许模型调用、10 个仅手动调用，清单见[架构](architecture.md#整包组合)。保留工程能力、自动执行入口和实际依赖，手动流程由用户显式选择，不承诺单独安装。任何 Skill 都不能自动调用手动入口或读取其正文绕过限制；自动能力可具名组合，把同一判断保留在一个权威位置，不推导固定长链。已有普通材料足以完成时直接消费。

主文保留进入任务必需的判断和可执行方法；专门知识、解释和实例可以完整放在有明确读取触发的 reference，确定性动作交脚本。比较整个实际阅读路径，不以主文或 reference 缩短证明精简；也不以恢复原版为由让所有任务加载全部材料。引用和脚本从实际安装位置解析，不能假定业务 cwd 含源码。

Description 负责帮助发现入口，应简短且可区分，不塞流程或近义词堆叠；实际发现及手动菜单行为由宿主和版本决定，元数据不是通用访问控制。一般不要求用户逐阶段批准；`grilling` 保留原版轮次、输出格式和共同理解确认，不能用减少人工接力为由跳过。

## 证据与机械化

验收观察消费者关心的行为，用能推翻错误实现的最小证据。结构、目录和引用检查只证明可达性，不证明自然触发或实际执行；模型自评与字段齐全不算结果证明。

类型、lint、schema、测试、hook 和脚本可以可靠裁决的规则不长期堆在 Prompt。精确 schema 只服务真实机器消费者，不给所有 Skill 统一报告格式。永久测试保护行为、边界和失败机制，不钉文案或内部实现。

hook 和扩展旨在传递固定约束，不直接检测过度设计，也不为每次工具调用重复注入。现有 pi/OMP `before_agent_start`、适用宿主生命周期 hook 和 Cursor 插件规则是薄适配；实际加载及不同请求生命周期须分别验证。模式、分支恢复和状态栏只在存在可变状态需求时有意义；验证层次见 [Harness 指南](harness-engineering.md#环境可读性)。

## 维护与对照

变化同步触发、正文、references、脚本、索引、具名消费者与来源。去掉 obsolete 文件和别名，保留许可证及 credits；普通局部修改不增加仪式文档。

需要行为对照时，在相同模型、工具、输入、授权和验收下比较基础、来源或候选，保留实际加载范围、执行轨迹和产物。少量案例只能支持对应场景，不能声称普遍提升；显式加载不能记成自然发现。不建立无持续消费者的永久评测平台。

模型或宿主升级后，根据实际行为重新检查哪些机制还承重。删除有证据表明无效的默认行为复述和无消费者模板；方法、理由与示例不因“模型应该懂”自动失去价值，安全、授权和实际机器协议更不能据此删除。方法细节见 [`writing-for-agents` 的判据](../skills/writing-for-agents/references/criteria.md)。
