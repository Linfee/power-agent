# DD-004: AGENTS.md 精简结构

## 背景

AGENTS.md 是 Agent 的首要入口文件。需要决定它应包含多少信息。

## 约束

- Agent 上下文窗口有限，首次加载的信息量影响后续推理质量
- 所有重要信息必须可达，但不必全部在首屏
- 当所有事情都标为重要，就没有什么重要

## 方案对比

| 方案 | 优势 | 劣势 | 复杂度 |
|------|------|------|--------|
| A: 巨型 AGENTS.md | 一站式、无需跳转 | 上下文拥挤、重点丢失、易腐化 | S |
| B: 精简目录式（≤200 行）| 重点突出、按需深入 | 需要维护导航指针 | M |

## 决定

选择方案 B：AGENTS.md 控制在约 200 行以内，作为目录（地图）而非百科全书。具体知识下沉到 `docs/` 的结构化文件中，AGENTS.md 通过导航表指向它们。

## 后果

- 需要 `docs/` 目录承接具体内容
- 需要维护导航指针的有效性（dev-docs-maintain 负责）
- 新增知识时需要判断放在 AGENTS.md 还是 docs/ 下
