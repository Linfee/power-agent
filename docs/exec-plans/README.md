# 执行计划目录

计划用于跨会话参照、人审或外部消费者，不是所有开发的前置条件。执行状态在项目选定的唯一 tracker；计划保存目标、关键决定、依赖、验收和状态源指针，不复制进度。研究、建议、内容和明确小任务不为形式进入本目录。

## 目录约定

`active/` 保存仍需恢复的计划；`completed/` 保存完成后的历史。选择消费者确需的最小文件集合，不强制 review-contract、Gate 或任务卡。`YYYY-MM-DD-topic/` 是目录命名，不规定内容模板。

历史材料保留当时的名称、格式和证据，不能当现行运行时指令。失效计划只有核对真实状态后才标明取代；不为历史链接重建退役入口。
