# 执行计划目录

本目录在需要跨会话恢复、供人审或为多个执行者提供稳定参照时，存放软件资产变更的开发计划。计划不是所有开发工作的默认前置条件；研究、运营、内容制作、长期知识维护与边界清楚的直接工作不因形式而进入本目录。

## 进行中

`active/` 中的每个子目录是一个仍可恢复的计划。选择能让实际消费者理解目标、范围、关键决定、依赖、验收、证据、阻塞与风险的最小文件集合。可以使用一个 `plan.md`，也可以在现有消费者需要时拆出额外材料；`review-contract.md`、状态字段、Gate 或固定任务卡不是目录级强制协议。

## 已归档

`completed/` 保存已完成工作的历史材料。历史计划保留其当时的格式和证据，不把旧流程反向解释为当前运行时规则。

## 命名

计划目录使用 `YYYY-MM-DD-topic/`。文件名应表达真实消费者，例如单一事实源、背景材料或任务图；不要为满足目录习惯创建无人读取的文件。
